Added PlainDisposable, PlainSyncDisposable, and PlainAsyncDisposable, which offer the same disposal claim, override, and notification behavior as their counterparts but do not notify of property changes and declare no finalizer. Because they declare no finalizer, disposal will not occur if consumers neglect it; hold unmanaged resources in a SafeHandle or derive from the notifying counterpart instead. Their synchronous extension point is DisposeCore, which takes no parameter, since without a finalizer there is no caller that could pass false.
Corrected: a disposal base class released its claim before its Disposed handlers had run, so a handler that threw left the object with its resources released and its claim available, and a second call to Dispose would run the cleanup again. The claim, the suppression of finalization, and IsDisposed are now all settled before any event is raised.
