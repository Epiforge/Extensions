FastInvoker, the FastInvoke and FastDefault extensions, FastComparer and FastEqualityComparer now work where the runtime cannot generate code, as under Native AOT and on iOS: there they invoke and compare through reflection rather than through generated methods, with the same results, including comparisons which honor a type's own IComparable<T> or IEquatable<T> as the default comparers do, and exceptions which arrive unwrapped.
The package is marked as compatible with ahead-of-time compilation, and the members which need generated code or reflect over what trimming may remove now say so: ExceptionExtensions.GetFullDetails, ReflectionExtensions.GetImplementationEvents, GetImplementationMethods and GetImplementationProperties, DynamicPropertyChangeNotifier, DynamicDisposable, DynamicAsyncDisposable and DynamicSyncDisposable.
IsDisposed on the disposable base classes now reads with acquire semantics, so a thread waiting on another thread's disposal sees it; before, a loop polling IsDisposed could be compiled to read the field once and never finish, as it did on .NET 10 on Apple Silicon and on Linux.
Without dynamic code, the invokers and comparers now cast their instance and arguments as the generated ones do, so they accept, convert and refuse the same values with the same exceptions: null for a value-type parameter throws NullReferenceException rather than passing the type's default, a value which would need widening, such as a short for an int, throws InvalidCastException rather than being widened, and an instance or argument of the wrong type throws InvalidCastException or NullReferenceException rather than ArgumentException or TargetException.
FastInvoke now refuses the wrong number of arguments with the ArgumentException FastInvoker throws, where before too few threw IndexOutOfRangeException and too many were ignored; a null argument list still means none. A member which takes or returns a reference, a pointer or a by-reference-like value now throws NotSupportedException when invoked, and an open generic member or an abstract class's constructor InvalidOperationException, where before they threw InvalidProgramException or returned null. FastDefault throws ArgumentException for void, by-reference-like and open generic types, where before it threw ArgumentException, BadImageFormatException or InvalidProgramException.
FastEqualityComparer hashes null as zero for a value type without its own IEquatable<T>, Nullable<T> included, as it already held null equal to null. On .NET 6, FastGetValue and FastSetValue call PropertyInfo.GetValue and SetValue as they do on .NET 7 and later, so null set to a value-type property gives it the type's default there too.
