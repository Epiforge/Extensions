Comparing two values of a value type which does not implement IEquatable<T> for equality no longer allocates. Such values were received already boxed, unboxed, and then handed to a comparer which boxed one of them again to reach the very same comparison; they are now compared as they arrive. Observing an expression whose result is such a type — the key-value pair a projection produces, for instance — allocates forty-eight bytes less every time it is re-evaluated.
