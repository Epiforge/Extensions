An expression containing a default value, such as the last branch of a chain of conditionals which a formula or rule engine emits for a switch with no default of its own, can now be observed, and is observed by subscribing directly to its change sources where the rest of the expression is eligible. Previously observing one threw NotSupportedException whether or not direct subscription was enabled.
A query reading the maximum or minimum of a concatenation, an element of one, or filtering one now enumerates it rather than reading it element by element through its indexer, which takes a lock on every read. The maximum of two thousand elements concatenated from two projections takes 3.7 μs where it took 46.0 μs, and from two lists 3.8 μs where it took 26.4 μs, at a cost of 131 to 184 bytes more each time such a query is constructed. A prepending or an appending now reports whether its source is costly to read by index, as a slice already did, so that what reads it chooses the same way.
IndexOf on a query which is costly to read by index, which includes a filter, a projection, a flattening, one delivered through a synchronization context and a concatenation, returned -1 whatever it was given; it now returns the element's position. On other queries it returned the right position, but looking for an element which was not there enumerated the whole query once for every element it held; it now reads each element once.
