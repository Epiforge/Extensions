A property whose change notifications the observer has been told to ignore is now treated as a static property is wherever it is read: it is read once and kept, never subscribed to, and read again when what it is read through moves to another object. A read of one through something which can change, which sent the whole expression to the graph, is now observed directly, and when it is read again after such a move is not specified: the graph reads it when what it is read through announces the move, an observation evaluated directly when an evaluation next reaches it through the new object, and the two can differ only about a value which changed without its change being followed. A read through a value type which can change still builds the graph. Over a thousand observations of such a read beside a property which is followed, building and disposing them takes 184 µs and 578 kilobytes rather than 2,825 µs and 3,639 kilobytes, less than the 261 µs and 773 kilobytes the same expression takes with nothing ignored; a change to the followed property takes 45 µs rather than 64, and a move of what the ignored property is read through 48 µs rather than 88.
A property read on something which cannot change, through a value of a sealed type implementing none of the notification interfaces, is held as something which cannot change, so an ignored property read through it, or a call over it whose value the observer disposes of, is observed directly rather than by the graph.
